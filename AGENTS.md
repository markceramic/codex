# Instructions for Codex tasks in this repository

- Use Thai for user-facing work unless the user requests another language.
- This repository is shared context for occasional Cloud work while the user's Mac is off. The Mac remains the primary workspace. Do not assume local Mac files, browser sessions, or custom skills are available in Cloud.
- Identify the business and destination for each task from the user's request. Work may involve Mark Ceramic, THE MUG, MUGSCREEN, Nano Florist, and other projects; do not mix their facts, styles, accounts, or assets.
- Start with files in this repository, supplied attachments, and available connected services. If a required source is absent, state the exact missing file or access and continue useful independent work.
- Use `MOBILE_WORKFLOWS.md` as the task intake guide. Treat its example prompts as templates; verify prices, product claims, dates, tax treatment, and account destinations from current task evidence.
- Preserve original Mac skills. Add Cloud copies only after reviewing their instructions and referenced files for portability and sensitive data. A skill on the Mac is not available here merely because its path is known.
- Keep credentials, cookies, service account keys, customer personal data, real quotations, and large media out of Git. Use secure environment settings and approved business or file services for them.
- Before changing a live website, account, advertisement, post schedule, or quotation, verify the destination and current state with the available integration. Report what was actually saved or published.
- Cloud task processes may stop between sessions. Put work that must run continuously on an appropriate hosted service.
